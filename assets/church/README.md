# Church Graphics Folder

## Instructions:
1. Download your church graphics from Canva
2. Save Sunday service graphics and other church designs here
3. Recommended format: JPG or PNG
4. Suggested naming: `church-sunday-jan-2026.png`, `church-event-01.png`

## After Adding Images:
Update the HTML file (index.html) around line 186-190:

```html
<!-- Church Graphics -->
<img src="assets/church/sunday-1.png" alt="Sunday service graphic design" class="grid-item" data-category="church" loading="lazy">
<img src="assets/church/sunday-2.png" alt="Church event promotional design" class="grid-item" data-category="church" loading="lazy">
```

## Tips:
- Organize by date or event type
- Include special events, holidays, regular services
- Keep designs recent (last 6-12 months preferred)
