# Shopify Designs Folder

## Instructions:
1. Download your Shopify design work from Canva
2. Save them in this folder (banners, product pages, store layouts, etc.)
3. Recommended format: JPG or PNG
4. Suggested naming: `shopify-banner-01.png`, `shopify-product-layout.png`

## After Adding Images:
Update the HTML file (index.html) around line 181-185:

```html
<!-- Shopify Designs -->
<img src="assets/shopify/design-1.png" alt="Shopify store banner design" class="grid-item" data-category="shopify" loading="lazy">
<img src="assets/shopify/design-2.png" alt="Product page layout design" class="grid-item" data-category="shopify" loading="lazy">
```

## Tips:
- Include various types: banners, product pages, store sections
- Show before/after if available
- Mention client name in alt text if allowed
