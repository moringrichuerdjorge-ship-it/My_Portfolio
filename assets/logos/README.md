# Logo Designs Folder

## Instructions:
1. Download your logo designs from Canva
2. Save them in this folder with descriptive names
3. Recommended format: PNG with transparent background
4. Suggested naming: `logo-company-name.png` or `logo-brand-01.png`

## After Adding Images:
Update the HTML file (index.html) around line 175-180:

```html
<!-- Logo Designs -->
<img src="assets/logos/logo-1.png" alt="Logo design for [Client Name]" class="grid-item" data-category="logos" loading="lazy">
<img src="assets/logos/logo-2.png" alt="Brand identity logo design" class="grid-item" data-category="logos" loading="lazy">
```

## Tips:
- Use descriptive alt text for SEO
- Keep file sizes under 500KB for faster loading
- Use consistent dimensions when possible
